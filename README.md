# GabAI

Offline-first safety companion for Marinduque, Philippines. Built with Expo SDK 58, React Native, and Expo Router for Android and iOS, with a browser preview.

GabAI combines bundled safety guides, an emergency hotline directory, a local emergency profile, photo capture, and a chat assistant. Chat supports an optional on-device Gemma model or Google Gemini, with bundled-guide fallback.

## Start developing

```sh
npm ci
npx expo start --dev-client
```

Install a compatible development build for native AI and audio. For a browser preview, run `npm run web`. See [development](docs/development.md) for build profiles and checks.
